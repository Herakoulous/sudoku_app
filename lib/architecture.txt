/*
SCOPE: This document describes the complete, functional Sudoku app implementation.

automatic note erasing, and comprehensive undo/redo with action grouping.

=============================================================================
PROJECT STRUCTURE
=============================================================================

ACTIVE IMPLEMENTATION (lib/):
- lib/main.dart                    → App entry point
- lib/data/puzzles.dart            → Static puzzle definitions (4 puzzles)
- lib/services/save_service.dart   → Persistence via SharedPreferences
- lib/models/
    • position.dart                → Grid coordinates (immutable)
    • action.dart                  → Undo/redo action records with grouping
    • sudoku_cell.dart             → Cell state with JSON serialization
    • game_state.dart              → Complete game state with factory
    • variant_constraint.dart      → Variant constraint system (unused)
- lib/controllers/
    • game_controller.dart         → Business logic (ChangeNotifier)
- lib/widgets/
    • menu_screen.dart             → Start screen
    • game_screen.dart             → Main game screen with timer
    • game_header.dart             → Header with timer, stars, controls
    • sudoku_grid.dart             → Interactive 9x9 grid with drag selection
    • number_pad.dart              → Input pad with modes and actions
    • rules_popup.dart             → Help dialog

INACTIVE FOLDERS (placeholders):
- managers/, models/, screens/, widgets/ (outside lib/) → Empty stub files
- utils/ → Empty stub files

=============================================================================
CORE DATA MODELS (lib/models/)
=============================================================================

1) POSITION (position.dart)
   - Immutable value object: row, col coordinates
   - Equality/hashCode, toString()
   - JSON serialization: toJson(), fromJson()

2) ACTION (action.dart)
   - enum ActionType: SET_NUMBER, CLEAR, TOGGLE_SIDE_NOTE, TOGGLE_CENTER_NOTE, 
     SET_COLOR, GROUP, ERASE_NOTE
   - class Action: type, position, oldCell, newCell, timestamp, groupId
   - Supports action grouping for atomic undo/redo operations
   - JSON serialization: toJson(), fromJson()

3) SUDOKU_CELL (sudoku_cell.dart)
   - Core cell data: row, col, number, sideNotes(Set<int>), centerNotes(Set<int>)
   - Visual state: cellColor(Color?), isSelected, isHighlighted, isError, isGiven
   - Constructors: default, given({row,col,number}), empty({row,col})
   - copyWith() with clearNumber/clearColor flags for precise state updates
   - Mutators: clear(), toggleSideNote(), toggleCenterNote(), setNumber(), setColor()
   - Computed properties: isEmpty, hasUserInput, sortedSideNotes, sortedCenterNotes
   - JSON serialization: toJson(), fromJson()

4) GAME_STATE (game_state.dart)
   - Enums: GameMode { NORMAL, SIDE_NOTES, CENTER_NOTES, COLORING }
   - Enums: SelectionMode { SINGLE, MULTIPLE }
   - Core state: grid (9x9 SudokuCell), currentMode, selectionMode
   - Selection tracking: selectedCells(Set<Position>), highlightedCells(Set<Position>)
   - Game metadata: difficulty, puzzleId, elapsedTime, isPaused
   - History system: actionHistory(List<Action>), currentActionIndex
   - Factory: newGame(puzzleId, difficulty) → builds grid from Puzzles
   - JSON serialization: toJson() (includes actionHistory), fromJson()

5) VARIANT_CONSTRAINT (variant_constraint.dart) - UNUSED
   - enum ConstraintType: KROPKI_WHITE, KROPKI_BLACK (with placeholders for future variants)
   - class VariantConstraint: type, row1, col1, row2, col2
   - Methods: isBetween(), involvesCell(), getOtherCell(), orientation
   - JSON serialization: toJson(), fromJson()
   - Note: This is a prepared system for future Sudoku variants but is not currently integrated

=============================================================================
BUSINESS LOGIC (lib/controllers/game_controller.dart)
=============================================================================

GAME_CONTROLLER extends ChangeNotifier:
- State management: owns GameState instance, notifies listeners on changes
- Persistence: saveProgress(), loadProgress() via SaveService
- Cell selection: handleCellTap(row,col), toggleMultipleSelection()
- Input processing: handleNumberInput(number) with mode-aware logic
- History management: addAction(), addGroupedActions(), undo(), redo()
- Grid operations: eraseSelectedCells(), restartPuzzle()
- Validation: validateGrid() (marks conflicts), getRelatedCells(), updateHighlights()
- Timer control: startTimer(), pauseTimer()
- Queries: getSelectedNumber(), countNumber(), isNumberComplete()

ADVANCED FEATURES:
- Automatic note erasing: eraseNotesInRelatedCells() removes conflicting notes
- Action grouping: multi-cell operations are atomic for undo/redo
- Smart input handling: mode-aware number input with conflict detection

=============================================================================
SERVICES (lib/services/save_service.dart)
=============================================================================

SAVE_SERVICE (static methods):
- Storage: SharedPreferences key-value store
- Key format: 'sudoku_game_<puzzleId>' + '<key>_timestamp'
- Operations: saveGame(GameState), loadGame(puzzleId), clearSave(puzzleId)
- Utilities: getSavedGameIds(), getSaveTimestamp(puzzleId)
- Serialization: JSON via GameState.toJson()/fromJson()

=============================================================================
STATIC DATA (lib/data/puzzles.dart)
=============================================================================

PUZZLE_DATA:
- Structure: id, difficulty, grid (0=empty, 1-9=given numbers)
- Predefined puzzles: easy1, easy2 (difficulty 3), medium1 (difficulty 5), hard1 (difficulty 8)
- API: getPuzzle(id), getAllPuzzleIds()

=============================================================================
UI LAYER (lib/widgets/)
=============================================================================

MENU_SCREEN (menu_screen.dart):
- Simple start screen with title and START GAME button
- Navigation: pushes GameScreen(puzzleId: 'easy_001', difficulty: 3)

GAME_SCREEN (game_screen.dart):
- Stateful widget managing GameController lifecycle
- Timer management: Timer + ValueNotifier<Duration> for efficient updates
- Layout: GameHeader (ValueListenableBuilder) + SudokuGrid + NumberPad
- Lifecycle: loads saved game, starts timer, persists on dispose

GAME_HEADER (game_header.dart):
- Display: puzzle title, difficulty stars (0..difficulty), formatted timer
- Controls: exit button (Navigator.pop), restart button (controller.restartPuzzle())
- Timer formatting: MM:SS format

SUDOKU_GRID (sudoku_grid.dart):
- GridView.builder rendering 81 cells
- Visual layering: background → borders → colored borders → error borders → content
- Content rendering: main number OR side notes OR center notes (stacked when both)
- Gesture handling: tap selection, drag selection with continuous tracking
- Drag selection: onCellDragStart/Update/End with position calculation
- Styling: getCellBorder(), getCellBackgroundColor() with priority system

NUMBER_PAD (number_pad.dart):
- Three-row layout: modes + undo + 1-3, multi + redo + 4-6, help + erase + 7-9 + center
- Mode buttons: NORMAL, SIDE_NOTES, CENTER_NOTES, COLORING with visual feedback
- Action buttons: undo/redo (enabled based on history), erase, help
- Multi-selection toggle with visual state indication
- Color mode: number buttons show colors instead of numbers
- Controller integration: delegates all actions to GameController

RULES_POPUP (rules_popup.dart):
- AlertDialog with comprehensive Sudoku rules and gameplay tips
- Static show(context) method for easy invocation

=============================================================================
DATA FLOW ARCHITECTURE
=============================================================================

USER INTERACTION FLOW:
User Input → UI Widget → GameController → GameState Mutation → notifyListeners() → UI Rebuild

SPECIFIC FLOWS:
- Cell selection: SudokuGrid → handleCellTap() → updateHighlights() → UI update
- Number input: NumberPad → handleNumberInput() → mode-aware processing → action creation → history update
- Drag selection: SudokuGrid → onCellDragUpdate() → position calculation → selection update
- Timer updates: GameScreen Timer → ValueNotifier → GameHeader rebuild
- Persistence: GameState ↔ SaveService ↔ SharedPreferences (JSON)

=============================================================================
ADVANCED FEATURES
=============================================================================

DRAG SELECTION:
- Continuous drag tracking across multiple cells
- Position calculation accounting for padding and cell size
- Prevents tap events after drag operations
- Visual feedback during drag operations

AUTOMATIC NOTE ERASING:
- When placing a number, automatically removes that number from notes in related cells
- Creates grouped actions for atomic undo/redo
- Prevents conflicting notes from remaining in the grid

ACTION GROUPING:
- Multi-cell operations are grouped with shared groupId
- Undo/redo treats grouped actions atomically
- Prevents partial undo states

SMART VALIDATION:
- Real-time conflict detection across rows, columns, and 3x3 boxes
- Visual error indication with red borders
- Maintains game state integrity
